# yodovim

Минималистичная конфигурация Neovim в черно-белом стиле. Интерфейс в духе IDE: файловое дерево, вкладки, статус-лайн, командная палитра и начальный экран.

## Требования

- Neovim 0.11+
- git, make, cc (для сборки плагинов)
- fd, rg (для поиска и grep)
- lazygit (для git-статуса)
- nodejs (для pyright)

## Установка

```sh
git clone https://github.com/saochinomi/yodovim.git ~/.config/nvim
nvim
```

При первом запуске lazy.nvim установит все плагины. LSP-серверы (pyright, clangd, lua_ls) и инструменты (black, ruff, clang-format, stylua) подтянутся автоматически через Mason, это может занять пару минут.

## Хоткеи

Лидер клавиша: `Space`

### Файлы и поиск

| Клавиша | Действие |
| --- | --- |
| `Space f` | Найти файл |
| `Space s` | Grep по проекту |
| `Space b` | Открытые буферы |
| `Space p` | Командная палитра |
| `Space e` | Файловое дерево |
| `Space h` | Справка |

### Git

| Клавиша | Действие |
| --- | --- |
| `Space gg` | Lazygit (плавающее окно) |
| `Space ghp` | Превью хунка |
| `Space ghb` | Blame строки |
| `Space ghs` | Застейджить хунк |
| `Space ghr` | Откатить хунк |
| `Space ghd` | Диф текущего файла |

### LSP

| Клавиша | Действие |
| --- | --- |
| `K` | Hover |
| `gd` | Определение |
| `gr` | Ссылки |
| `Space a` | Code action |
| `Space r` | Переименование |
| `Space d` | Диагностика |
| `[d` / `]d` | Пред./след. диагностика |

### Окна и вкладки

| Клавиша | Действие |
| --- | --- |
| `Space h/j/k/l` | Переход между окнами |
| `Space -` / `Space \|` | Горизонт./вертик. сплит |
| `Space c` | Закрыть окно |
| `Ctrl+s` | Сохранить |
| `Ctrl+`` ` | Терминал |
| `Space qs` | Выбор сессии |

### Начальный экран

`Space da` - показать dashboard. Сессии сохраняются автоматически при выходе и восстанавливаются при запуске.

## Структура

```
init.lua
colors/yodovim.lua          тема
lua/config/                 опции, хоткеи, автокоманды
lua/plugins/                конфигурация плагинов
```
