# yodovim

#### [Установка](#-установка) · [Хоткеи](#-хоткеи) · [Темы](#-темы) · [Структура](#-структура) · [Лицензия](#-лицензия)

Минималистичная конфигурация Neovim в духе IDE: начальный экран, файловое дерево, вкладки, статус-лайн, автодополнение и LSP для 20 самых популярных языков. Легко переносится на любой Linux-сервер, всё ставится само при первом запуске.

## ✨ Возможности

- Начальный экран с недавними файлами, сессиями и сменой темы
- Поддержка 20 популярных языков: LSP, подсветка синтаксиса, автодополнение
- Автоматическая установка серверов и инструментов через Mason
- Форматирование при сохранении: Ruff, prettier, clang-format, gofmt, shfmt, stylua
- Проверка типов в Python через Mypy и линт через Ruff
- Файловое дерево, вкладки, плавающий терминал, lazygit
- 11 тем на выбор, стандартная TokyoNight
- Быстрый запуск, меньше 50 мс
- Цветные иконки файлов, в том числе для системных файлов Linux

## 🌟 Установка

Если уже стоит Neovim, сделайте резервную копию конфигурации и удалите его следы:

```sh
rm -rf ~/.config/nvim ~/.local/share/nvim ~/.local/state/nvim ~/.cache/nvim
```

Требуется только Neovim 0.11+ и git:

```sh
mkdir -p ~/.config/nvim
git clone https://github.com/saochinomi/yodovim.git ~/.config/nvim
nvim
```

При первом запуске lazy.nvim установит плагины, Mason подтянет LSP-серверы (pyright, clangd, lua_ls, tsserver, gopls и другие) и инструменты форматирования. Займёт пару минут, дальше всё работает само.

Дополнительно для быстрого поиска и git можно поставить `fd`, `rg` и `lazygit` через пакетный менеджер.

## 🚀 Хоткеи

Лидер клавиша: `Space`

### Файлы и поиск

| Клавиша | Действие |
| --- | --- |
| `Space f` | Найти файл |
| `Space s` | Grep по проекту |
| `Space b` | Открытые буферы |
| `Space p` | Командная палитра |
| `Space e` | Файловое дерево |
| `Space h` | Справка |
| `Ctrl+n` | Новый файл |
| `Ctrl+s` | Сохранить |

### LSP и диагностика

| Клавиша | Действие |
| --- | --- |
| `K` | Hover |
| `gd` | Определение |
| `gr` | Ссылки |
| `Space a` | Code action |
| `Space r` | Переименование |
| `Space d` | Диагностика |
| `[d` / `]d` | Пред./след. диагностика |
| `Tab` | Принять подсказку автодополнения |

### Git

| Клавиша | Действие |
| --- | --- |
| `Space gg` | Lazygit |
| `Space ghp` | Превью хунка |
| `Space ghb` | Blame строки |
| `Space ghs` | Застейджить хунк |
| `Space ghr` | Откатить хунк |
| `Space ghd` | Диф файла |

### Окна и сессии

| Клавиша | Действие |
| --- | --- |
| `Space h/j/k/l` | Переход между окнами |
| `Space -` / `Space \|` | Горизонтальный/вертикальный сплит |
| `Space c` | Закрыть окно |
| `Ctrl+`` ` | Терминал |
| `Space qs` | Выбор сессии |
| `Space da` | Начальный экран |

Сессии сохраняются при выходе и восстанавливаются при запуске. После закрытия последнего файла снова открывается начальный экран.

## 🎨 Темы

Кнопка `t` на начальном экране открывает список тем. Выбор запоминается и применяется при следующем запуске.

- TokyoNight (стандартная)
- yodovim (чёрно-белая)
- Catppuccin, Gruvbox, Nord, Dracula, Rose Pine, Everforest, Nightfox, Kanagawa, One Dark

## 📁 Структура

```
init.lua                 точка входа
colors/yodovim.lua       чёрно-белая тема
lua/config/              опции, хоткеи, темы, сессии
lua/plugins/             конфигурация плагинов
```
